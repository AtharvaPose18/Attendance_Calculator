# Student Attendance Calculator
A simple Java program that calculates a student's attendance percentage based on total working days and days attended.

## Features
- Accepts total working days and days attended as input
- Calculates attendance percentage
- Checks eligibility based on a 75% attendance requirement
- Validates invalid inputs

## Technologies Used
- Java
- Scanner class
- If-else statements
- Logical operators (`||`)
- Arithmetic operations

## How to Run
1. Download AttendanceCalculator.java.
2. Open a terminal in the folder containing the file.
3. Compile the program:
   javac AttendanceCalculator.java
   
4. Run the program:
   java AttendanceCalculator
  

## Example Output
Enter total working days: 100
Enter days attended: 82
Attendance: 82.0%
Attendance status: Eligible

## Purpose
This project was created to practise Java fundamentals, percentage calculations, input validation, and logical operators.
